# Fundamentals

This directory is reserved for foundational Python and SQL exercises personally written by the project owner.

## Purpose

These exercises demonstrate core programming and data analysis fundamentals that underpin the AbhiAI Analytics Engine. They are **not** auto-generated, backdated, or fabricated.

## Structure

```
fundamentals/
├── python/     # Python exercises (to be added)
└── sql/        # SQL exercises (to be added)
```

## Planned Content

### Python (`fundamentals/python/`)
- Data structure manipulation (lists, dicts, sets)
- Pandas basics (DataFrame creation, indexing, aggregation)
- DuckDB basics (connection, queries, parameters)
- File I/O (CSV, Parquet, JSON)
- Error handling and validation
- Testing patterns (pytest)

### SQL (`fundamentals/sql/`)
- SELECT, WHERE, GROUP BY, ORDER BY
- Aggregations (SUM, AVG, COUNT, MIN, MAX)
- Window functions (ROW_NUMBER, LAG, SUM OVER)
- CTEs and subqueries
- Date/time functions
- Parameterized queries (safety)
